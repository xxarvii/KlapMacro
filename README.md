## 🔑 Obtenir votre clé d'accès gratuite

Pour déverrouiller et utiliser le logiciel, suivez ces 3 étapes simples :

1. Rejoignez notre serveur Discord officiel :  
   👉 **[discord.gg/re2UJfgqZY](https://discord.gg/re2UJfgqZY)**
2. Rendez-vous dans le salon textuel dédié : **`#🔑-code`**.
3. Tapez la commande :
   ```
   /code
   ```
4. Votre clé unique (ex : `RL-XXXX-XXXX`) vous sera envoyée instantanément en message privé !
5. Copiez-la dans **Klap Macro | RL** pour vous connecter. La clé est automatiquement sauvegardée pour les prochains démarrages.

## 📥 Installation & Lancement

1. Téléchargez la dernière version de **`RocketLeagueMacros.exe`**.
2. Lancez l'application (l'élévation Administrateur est demandée automatiquement pour communiquer avec le jeu).
3. Entrez votre clé obtenue via `/code` sur Discord.
4. Configurez vos touches selon vos préférences dans l'onglet **Touches**.
5. Lancez Rocket League et profitez de macros fluides et réactives !
